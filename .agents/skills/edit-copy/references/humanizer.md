# Humanizer patterns

Condensed from the source above and rewritten for this repo. It
complements `ai-tells.md` with the patterns that hide in structure and
attribution rather than in single words.

## Inflated significance

"Serves as", "stands as", "a testament to", "pivotal", "underscores",
"broader trend", "evolving landscape", "lasting impact". Replace with the
concrete fact and why it matters to this reader; no borrowed gravitas.

## Promotional filler

"Vibrant", "rich", "groundbreaking", "seamless", "powerful", "must-have",
"nestled", "in the heart of", "showcasing", "commitment to". Replace
with a specific noun or a plain assertion.

## Fake depth

Trailing "-ing" clauses that pretend to analyse: "highlighting",
"underscoring", "reflecting", "encompassing", "fostering", "ensuring".
Split the sentence, or delete the clause; it usually restates the first
half.

## Vague attribution

"Experts say", "industry reports suggest", "observers note", "some
critics argue". Name the source and link it, quote the actual person, or
remove the claim. In this repo, a number with no snapshot path is
removed.

## Vocabulary clusters

Additionally, delve, crucial, intricate, interplay, landscape, robust,
valuable, key, enhance, leverage. Shorter, everyday words.

## Formulaic structure

Forced groups of three; "not only X but Y"; "it is not just X, it is Y";
false "from X to Y" spans; a generic "challenges and future prospects"
section; an upbeat closing that says nothing. Keep only the genuine
argument.

## Chatbot residue

"Great question", "I hope this helps", "let me know if", "here is an
overview", "let's dive in", knowledge-cutoff disclaimers. Delete on
sight.

## Over-styling

Too much bold, emoji, title-case headings, bullet lists whose every item
opens with an inline header, em-dashes, curly quotes where the project
uses straight ones. Style is set by `brand/voice.md`, not by the model.
