# Which skill fills which gap

Recommend only these skills, by exact name. When a gap needs an answer only the team has, say so first; a skill cannot invent it.

## ICP

| Gap | Skill |
| --- | --- |
| No ICP, or most sections empty or template | icp-from-materials |
| ICP inferred from the website only; needs deal data | icp-from-materials, with a CRM export or win/loss notes |
| Disqualifiers or loss patterns missing | loss-drivers, then icp-from-materials |
| Fit scorecard missing or uncalibrated | icp-scorecard |
| Priority verticals unsized or unargued | vertical-analysis |
| Target accounts lack firmographics or triggers | account-enrichment |

## Personas

| Gap | Skill |
| --- | --- |
| No personas, or a buying role missing from the set | persona-research |
| Personas exist but are thin, generic, uncited or near-duplicates | persona-review |
| No buyer voice: pains and objections not in the buyer's words | quote-extraction, theme-synthesis |

## Positioning

| Gap | Skill |
| --- | --- |
| No positioning, or the statement is template | positioning-framework |
| Category unclaimed or frame unargued | category-reading |
| Competitive alternatives missing or vague | find-competitors, competitor-deep-dive |
| Unique attributes unclear or table stakes | product-profile, competitor-deep-dive |
| Why-now trends missing or uncited | market-trends, market-research-report, analyst-report-digest |
| Proof points missing | quote-extraction, deal-summary |
| Unclear how answer engines describe the company | ai-answer-audit |

## Messaging

| Gap | Skill |
| --- | --- |
| No messaging, or pillars and narrative are template | messaging-framework |
| Messaging drifts from positioning or across channels | messaging-drift-audit |
| Objections not from real buyers | competitor-mentions-in-calls, loss-drivers, win-loss-interview-guide |
| Competitive objections unanswered | battlecard |
| Pillars lack proof | quote-extraction, deal-summary |

## Before any foundation

| Gap | Skill |
| --- | --- |
| No reliable list of what the company sells | company-profile, product-profile |
| A product change not reflected in the documents | product-change-impact |
