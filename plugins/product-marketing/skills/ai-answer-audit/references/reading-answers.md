# Reading the answers

Open this in procedure steps 4 to 6. In every case, report only what the answer literally says.

## Self-portrait answers

Record:

| Field | Rule |
| --- | --- |
| Category | In the answer's own words |
| Category match | Yes if it is the same market as the claimed category; a different label for the same market still matches |
| Strengths | At most four short phrases; never add one it does not give |
| Weakness | One sentence, or none; never soften a criticism it makes |
| Weakness fair | Fair and current against the positioning facts; outdated; or none raised |
| Wrong company | Yes if it describes a different company sharing the name |
| Verdict | See below |

Verdicts:

- **strong:** the category matches, the strengths overlap the claimed differentiators, and nothing stale is raised.
- **mixed:** the right space under the wrong label, or generic strengths.
- **off:** the wrong category, or a materially outdated description.

A description of a different company is a finding: mark it wrong company and report what it said,
never a charitable correction.

## Category answers

Record the definition (one sentence, its own words), every vendor named inside the category with
the frame it gives them (leader, challenger, niche, or none), and whether the company is among
them, however the answer spells it.

## Buying answers: mention detection

For every company or product the answer names as a vendor (not as a customer, a technology or a
data source), record:

| Field | Rule |
| --- | --- |
| Name | Exactly as written |
| Section | The heading it is filed under, verbatim; none if no heading |
| In category | Yes if a buyer shopping the market would plausibly also evaluate it. Judge against the market, never the company's marketing label |
| Is the company | Yes only if it is this company. A different business sharing the name is not; judge from the description and any cited domain |

Citations: answers embed inline source markers ("Northstar +2", a publication name). A name that
appears only as such a marker is a source, not a vendor. A vendor's own site is often also cited,
so a name in the source list that the answer also recommends is a vendor. Never fuse a trailing
citation onto the vendor before it ("Pagewise Northstar" is two names).

Out-of-category vendors are listed but left out of share of voice: an answer naming fifteen tools
across ten categories would otherwise turn the denominator into every tool that exists.

## Unifying vendor names

One vendor stays one row across answers and audits: lowercase, drop parentheticals and anything
after "by", ignore punctuation. "Pagewise", "Pagewise (status pages)" and "Pagewise by Pagewise
Labs" are one row.
