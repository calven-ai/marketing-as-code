# Asking and reading the assistants

Open this in procedure step 4.

## The question

Use the claimed label, verbatim, in this exact wording, so answers compare across assistants and
across readings:

> What is the "<claimed label>" category, and who are the leading vendors in it? Briefly define the space and name the main players.

If the claimed label is absent or not in buyer use, ask the same question a second time with the
market label, and report both readings separately.

Tell the user: one fresh chat per assistant, web search on, no custom instructions, and paste the
whole answer plus its list of sources. Record the date and whether web search was on.

## Reading one answer

Record what the answer said, and nothing else:

- **Definition:** one sentence, in the answer's own words.
- **Vendors:** every vendor it names inside the category, spelled as written, each with the frame it casts them in: leader, challenger, niche, or none given. Not customers, not technologies, not data sources.
- **Is it the company?** True only if the vendor is the company, however the answer spells it ("Beacon HQ" or "Beacon Incident Comms" is still Beacon). A different business that shares the name is not the company; judge from the description and any cited domain, and flag it as a namesake.
- **Names the company:** true if the company is among the vendors.

A name that appears only as an inline citation marker is a source, not a vendor. A vendor's own
site is often also cited; a name in the source list that the answer also recommends is a vendor.
Never fuse a citation onto the vendor next to it.

## Merging across assistants

- Count each vendor once per assistant, however many times one answer repeats it.
- Put the company on its own row whatever the answers called it, even at zero.
- Merge spelling variants of one vendor ("Pagewise", "Pagewise (status pages)", "Pagewise by Pagewise Labs") into one row by dropping parentheticals and anything after "by".
- An assistant that did not answer shrinks the count ("named by 2 of 3"); it is never counted as "did not name".

## The consensus sentence

One sentence in the assistants' own words, written so it reads as a quote of what they said, not a
summary about them. Never let one answer's wording dominate because it was longest.
