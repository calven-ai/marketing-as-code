# reports/recurring/social/

Organic social reports, one file per run, named by date: `YYYY-MM-DD.md`.
The `social-performance` skill writes them monthly from the snapshots in
`data/social/snapshots/`. `YYYY-MM-DD-listening.md` is the weekly listening
digest the `social-listening` skill writes from the `*-mentions.csv`
snapshots there.
