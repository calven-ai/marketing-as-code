# Consolidation examples

Open this file at step 4, before merging clusters. The test throughout: would a product marketer put these on one slide with one claim?

## Merge (same claim, different wording, symptom, cause or team)

- "updates go to every customer" + "unaffected accounts open tickets" + "no way to target by region" → **Unaffected customers get the outage alert**
- "status page post, email and macro written separately" + "the lead types updates between tickets" + "same update rewritten for Slack Connect" → **Incident updates are written by hand three times**
- "nobody knows what to say when it starts" + "first update takes twenty minutes" + "waiting for engineering to confirm wording" → **The first update is late because nobody owns the wording**
- "carrier invoices reconciled by hand" + "freight audit takes a week each month" + "spreadsheet matching of carrier charges" → **Carrier invoices are reconciled by hand every month**
- "new hires wait days for laptops" + "access requests bounce between teams" → **New hires wait days for equipment and access**

## Keep apart (one slide would need two claims)

- "updates go to every customer" vs "no record of who read the update" (wrong audience vs no visibility)
- "price too high for the budget" vs "pricing not disclosed in writing" (cost vs transparency)
- "slow implementation" vs "no internal owner for the rollout" (vendor effort vs customer staffing)
- "post-incident report written by hand" vs "customers never read the postmortem" (effort vs reach)

## Never

- A catch-all from clusters that share only a broad word: "manual work", "integration challenges", "data issues", "communication problems".
- A theme named after one member's detail when the others do not share it.

## Outliers

Clusters are first formed by wording, so one can hold a phrase making a different point ("pricing not disclosed in writing" inside a cluster about price being too high). Pull that phrase out to stand alone. Only clear cases: a different wording of the same point is not an outlier. A cluster always keeps at least one phrase.

## Labels

| Wrong | Right |
|---|---|
| Notification challenges | Unaffected customers get the outage alert |
| Reporting | Post-incident report is written by hand |
| Speed concerns | The first update takes twenty minutes |
| Pricing | Price is set per status page, not per team |
