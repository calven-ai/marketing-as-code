# Website check

Open this file at step 9. You are a gate here, not a generator: never add, rename or rewrite a candidate while checking it. You only judge the ones you have.

## How to check

1. Search the company's own website for each candidate's direction (a site search through web search works). Search results only locate pages; never conclude from a snippet.
2. Read the full text of the relevant pages: home, product, solution or industry pages, pricing, comparison pages, customer stories. Browse the site map at most twice; prefer search.
3. Decide the verdict from page text you actually read.

## Verdicts

| Verdict | When |
| --- | --- |
| covered | The site already leads with or substantially addresses the direction: the angle is already a primary message, the segment already has dedicated pages and proof, the pricing story already matches |
| gap | A passing mention, a buried paragraph or thin boilerplate is still a gap. Describe what is missing or only partly there |
| unverified | No page you read returned text on this direction (searches came back empty, or pages would not load). Never mark covered on a URL alone: a path like `/industries/healthcare` says a page exists, not what it says |

## Receipt (required for every candidate)

Record the pages you checked (paths are enough), what the site says today about this direction, and for a gap what is missing or partial. This is what lets a PMM trust the verdict.

## Retirement sanity check

For each tracked opportunity you proposed to retire, keep it instead when the site or the candidates' own evidence clearly still supports it, and say why.
