# Contributing to Marketing as Code

Thanks for wanting to make the starter better. Contributions of every size are
welcome: docs fixes, new agent definitions, template improvements, bug reports.

## Two ways to use this repo, one way to contribute

This repository is a template you copy and fill in. Be deliberate about which
mode you are in:

- **Running your own marketing:** use your own copy (template/fork). There,
  filling in `strategy/`, `content/`, and `memory/` with your real material is
  the point.
- **Contributing here:** PRs to this repo carry structure, templates, agents,
  and docs only. Never your (or anyone's) real strategy, customer data, or
  credentials.

## Ground rules

- Keep every template useful to a non-technical marketer: plain language,
  an example filled in, no unexplained jargon.
- One change per PR, with a sentence on who it helps.
- Be excellent to each other: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
