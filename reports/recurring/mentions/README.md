# reports/recurring/mentions/

AI answer-engine mention reports, one file per run, named by date:
`YYYY-MM-DD.md`. The `brand-monitor` skill writes them from the
`*-llm-mentions.csv` snapshots in `data/seo/snapshots/`.
`YYYY-MM-DD-sov.md` is the share-of-voice view the `ai-share-of-voice`
skill writes from the same snapshots.
