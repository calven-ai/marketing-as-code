# reports/qmr/

Quarterly marketing reviews, one folder per quarter: `<year>-q<n>/` holding
`report.md`, `data-checklist.md` and `dashboard.html`, started from
`../_templates/qmr/`. The `qmr` skill assembles it. Its Status line moves
through assembling, ready for review and final; once final, a new analysis
is a new file.
