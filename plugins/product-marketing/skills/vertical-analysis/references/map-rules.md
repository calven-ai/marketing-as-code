# Market map rules

Open this file at steps 3 to 7.

## Fields per vertical

| Field | Rule |
| --- | --- |
| Name | The industry's own name. Never a region, deployment model or size band |
| Size tier | large, mid or niche: how big this industry's spend in this market is, relative to the other verticals you list |
| Momentum tier | accelerating, steady or cooling: how fast it is heating up right now, relative to the others |
| Driver theme | 3 to 8 words: why demand for this category exists in this industry. A fact, not a recommendation. Must pass the relevance test |
| Short story | One factual sentence on the dynamics |
| Long story | 2 to 4 factual sentences on why the vertical is sized and moving the way it is |
| Sources | The pages you read for this vertical, with publisher, URL and date |
| Evidence strength | high, med or low (below) |
| Status (reruns) | new, updated or unchanged |

## Tiers

Assign both tiers by judgment from what you read; do not hunt for exact percentages, dollar figures or growth rates. A vertical can be both large and accelerating. Spread the tiers: a map where everything is large and steady tells the reader nothing.

## Evidence strength

| Level | Meaning |
| --- | --- |
| high | Direct, by-industry evidence from three or more distinct source domains |
| med | Some direct evidence, or one good source |
| low | Mostly inferred from adjacent or general material; the story says so |

Strength is capped by source breadth: count distinct domains, not pages.

## The relevance test

Ask of each driver: would this still be true if this category vanished? "Healthcare is heavily regulated" passes for every category, so it fails. "Clinical users need to know which workflows are down, by site" is about this category's job, so it passes.

## Describe, do not prescribe

Banned anywhere in the map: prioritize, focus on, target, win, go after, double down, and any other instruction. State what is true. The fit ranking is where judgment about the product goes.

## Cross-cutting drivers

3 to 6 forces that span several verticals. Each has a short title, a one-sentence and a 2 to 4 sentence factual story, its sources, and the verticals it touches.
