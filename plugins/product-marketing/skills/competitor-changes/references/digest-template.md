# Digest template

Markdown, ready to paste into a doc, a message or an email. Lead with what matters; the per-competitor detail follows for whoever wants it.

```
# Competitor changes: week of <YYYY-MM-DD>

<Competitors covered>. Window <YYYY-MM-DD> to <YYYY-MM-DD>. <n> pages read, <n> searches. Baseline: <last digest name and date, or "none: this is the baseline run">.

## What matters this week
1. **<Competitor>: <the move>** (High). <one sentence on what it means for you>
2. ...
(At most three. In a quiet week: "Quiet week. Nothing changed that affects a deal.")

## What to do
- <one action per High signal, and any Medium worth acting on: a message to sharpen, an objection to prep, a segment to defend, a battlecard to refresh with battlecard-refresh, a deep dive to update>

## Signals

### <Competitor>

#### <Title: the move, not the page> · <High / Medium / Low> · confidence <High / Medium>
<1 or 2 sentences naming the move.>
- <specific: amount, name, date, tier>
- <specific>
- <what is uncertain, if anything>

**So what:** <1 or 2 short sentences: the deal dynamic, segment, message or objection of yours it touches.>

**Consider:** <the single move to consider>

**Receipts:** "<verbatim quote>" ([<publisher: page title>](<URL>), <date published or changed>, read <YYYY-MM-DD>)

(next signal, highest severity first)

### <Competitor with no signals>
Checked <pages> and news; nothing new.

## Not included
| Competitor | Item | Why left out (repeat of <date> digest / restated / regional re-render / content, not an announcement / unverified: single thin source) |
| --- | --- | --- |

## Baseline for next run
Keep this section: next week's run compares against it.

### <Competitor> (<website>), checked <YYYY-MM-DD>
| Page | URL | What it says now |
| --- | --- | --- |
| Pricing | | <each plan: name, price, unit, billing basis; free tier or trial; add-ons> |
| Homepage | | <headline claim, category noun, stated audience> |
| Product / changelog | | <latest entry and its date> |
| Newsroom | | <latest release title and date> |
| Blog | | <latest post title and date> |
| Customers | | <named customers, count if stated> |
| Integrations | | <count, and names added since last run> |
| Trust / security | | <certifications with periods, data regions> |
| Subprocessors | | <named subprocessors> |
| Privacy / terms | | <last-updated date, notable clauses> |

**Reported so far** (titles and dates of every signal in this and earlier digests, newest first, so repeats can be caught):
- <YYYY-MM-DD> <title>
```

Per signal, keep the opening, the bullets and So what short: the opening says what the competitor did, the so-what says what it means for you; never restate one in the other. About 80 words for So what and Consider together. No filler such as "This is important because".
