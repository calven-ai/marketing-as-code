# AEO working memory

The `brand-monitor` skill's notes between runs, rewritten in place each run
and kept under about 150 lines. Current truth only; Git keeps the past.

## Watch

Items to re-check, each with its check date and decision rule.

## Known patterns

What the answers keep showing. A known pattern is not a finding.

## Events

Dated outside events that may move the numbers (a page shipped, a listing
won, an engine change).

## Standing questions

Questions the team wants answered every run.

## Candidates

Prompt ideas waiting for the quarterly review: text, track, tier, source.

## Set log

Every prompt added or retired and every brand added: date, id, reason.
