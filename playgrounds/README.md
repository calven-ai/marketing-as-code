# playgrounds/

**Kind:** code, deterministic scripts and throwaway prototypes the agent writes.

Come to meetings with prototypes, not decks.

Each prototype is a disposable subfolder an agent builds from one sentence: a
landing page mock, a campaign concept page, an email sequence preview, an ad
variant board, a storyboard. Throwaway by design, never production. After the
meeting, log the decision in `memory/` and archive the prototype.
