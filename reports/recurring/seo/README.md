# reports/recurring/seo/

Keyword and ranking deltas, one file per run, named by date:
`YYYY-MM-DD.md`. The `seo-analyst` skill writes them from the two most
recent snapshots in `data/seo/snapshots/`. `YYYY-MM-DD-decay.md` is the
content decay check the `content-decay-monitor` skill writes from the same
snapshots and `content/`.
