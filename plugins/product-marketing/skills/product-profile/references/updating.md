# Updating an existing profile

Open this in Update mode: the user supplies a profile plus new material (attached files, a changed web page, a release note, a pricing change).

## The principle: extend, do not rewrite

The existing profile is the record carried over from earlier sources, earlier runs and the team's own edits. Fold the new material into it; never replace it with a fresh write grounded only in today's sources. When torn between rewriting and merging, merge. An update that only adds use cases must not touch the overview or pricing.

## Steps

1. **Read every new source once.** Note a file that could not be read and one that was cut off; say so where you cite it.
2. **Map each source to the sections it informs.** One source may inform several sections; several sources may inform one. Website pages map roughly like this (use judgment):

   | Page | Usually informs |
   | --- | --- |
   | Homepage | Product Overview |
   | Product or feature page | Capabilities & Features, Integrations, Technical Architecture |
   | Solution or use-case page | Use Cases |
   | Any page describing tiers or prices | Pricing & Packaging |
   | Comparison page, or candid internal commentary | Differentiators & Known Weaknesses |
   | Security, trust or compliance page | Technical Architecture |
   | Press release, blog or resource | Skip, unless it surfaces a clear differentiator, weakness or shipped capability |
   | Event page | Usually skip |

3. **For each informed section, start from its current text and make the smallest set of edits:**
   - **Add** facts the section does not cover: a new feature, integration, use case, tier or deployment option.
   - **Refine** facts the new source states more precisely: a vague claim made concrete, a number updated.
   - **Correct** facts the new source directly contradicts. Replace only the contradicted statement and keep its surrounding context.
   - **Preserve** every fact the new source neither contradicts nor supersedes, even if it does not mention it. Silence is not evidence a fact is wrong.
4. **Cite only what is new or changed.** Existing citations stay on unchanged text.
5. **Leave untouched sections exactly as they were.** Do not tidy, reword or "clean up" a section no new source motivated.
6. **Report the update** at the top of the profile: one line per edited section naming the source that moved it, then the unchanged sections in one line.
