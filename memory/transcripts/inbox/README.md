# memory/transcripts/inbox/

Drop meeting transcripts here, named `YYYY-MM-DD-<meeting>.md` (`.txt` and
`.vtt` work too). A file you drag in needs nothing else; a file from a
connector carries the frontmatter described in [../README.md](../README.md).
The `chief-of-staff` skill processes each one and moves it to
`../processed/`. Nothing here is deleted.
